Keyboard
Built-in modes run in the keyboard itself

        

        
The keyboard cannot take a live stream of colors. When it follows the effect, rainbow, breathe, cycle, wave and ripple use the nearest built-in mode, and other effects show once the colors hold still. Each mode change is stored in the keyboard, so changes are limited to one every 5 seconds.

How to useDrag a zone to move it. Double-click a zone, or click a device name in the zone list, to select the whole device and move it as one. Ctrl- or Shift-click adds or removes single zones. The larger ringed dot is LED 1 of each zone: if the lights run the wrong way round, set the zone's LED 1 position or direction. Drag the round handle to resize a ring or move a line end. Effects such as waves and rings travel across this map, so place each light where it sits in the case.
          Select a zone or a device to rotate or mirror it in the Edit tab.
